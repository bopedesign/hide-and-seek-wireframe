# Hide and Seek Day Camp website

Astro site for Hide and Seek Day Camp (Seek Ministries, Canton, GA). This repo is the only source: edit here, build,
push `main`, and Vercel publishes it. Rules and where everything lives: `CLAUDE.md`.

```
npm install
npm run dev      # http://localhost:4321
npm run build    # builds and runs the page checker; must end with 0 errors
```
